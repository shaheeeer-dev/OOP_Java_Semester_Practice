Student Management System (Desktop Application)

📌 Problem Statement

Develop a Student Management System using Java Swing that allows an institute to manage student records efficiently.

🎯 Functional Requirements
•	Add new students (ID, Name, Department, Semester, CGPA)
•	Update student details
•	Delete student records
•	Display all students in a table
•	Search student by ID or name

🧠 OOP Concepts to Use
•	Classes & Objects → Student, StudentManager
•	Encapsulation → private fields + getters/setters
•	ArrayList for storing students
•	Exception Handling for invalid input
•	Swing GUI (JFrame, JButton, JTable, JTextField)

Library Book Management System

📌 Problem Statement

🎯 Functional Requirements
•	Add books (Book ID, Title, Author, Price, Availability)
•	Issue book to a student
•	Return a book
•	View available and issued books

🧠 OOP Concepts to Use
•	Inheritance → Book → IssuedBook
•	Polymorphism → overridden displayInfo()

Simple Banking System (ATM Simulator)

📌 Problem Statement

Design a Banking System (ATM Simulator) using Java Swing that allows users to perform basic banking operations.

🎯 Functional Requirements
•	Create bank accounts (Account No, Name, Balance)
•	Deposit money
•	Withdraw money
•	Check balance
•	Display transaction history

🧠 OOP Concepts to Use
•	Abstraction → abstract class Account
•	Inheritance → SavingsAccount, CurrentAccount
•	Encapsulation → secure balance handling
•	Exception Handling → insufficient balance
•	Swing GUI

💡 Real-World Logic
•	Withdrawal limit
•	Minimum balance rules
