## OOP Practice Problem 10: Shopping Cart System

**Scenario:**
An e-commerce system needs to manage shopping carts with different products.

**Requirements:**
-	Create a **class** `Item` with fields: `name`, `price`.
-	Create a generic class `ShoppingCart<T>` to store items.
-	Add methods:
-	`addItem(T item)`
-	`calculateTotal()`
-	Store multiple items in the cart and display the total cost.

**Focus:**
-	Generics
-	Encapsulation
-	Collections
